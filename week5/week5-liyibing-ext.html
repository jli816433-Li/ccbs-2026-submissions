Lecture 10 — Extension: When the memory disappears

Author: liyibing · Lecture 10 (2026-10-19) · CCBS 2026

One sentence: An autocatalytic controller can lose regulation when its last memory molecule disappears; basal synthesis permits recovery but shifts the deterministic set point.

The point I am adding

Lecture 10 shows that an autocatalytic controller integrates error in the logarithm of its molecular abundance, but warns that zero is absorbing.1 I extend that boundary argument by simulating discrete molecules and asking what changes if we give the controller a way to restart.

Work it

Let Z be the memory and X the regulated output. In my minimal model, Z produces X, while X removes Z. The four reactions and their stochastic event rates are:

Z → 2Z Memory replication: μZ
X + Z → X Memory removal: θXZ
Z → Z + X Output production: kZ
X → ∅ Output removal: γX

The corresponding deterministic equations are dZ/dt = (μ − θX)Z and dX/dt = kZ − γX. For positive Z,

d ln(Z/Zref)/dt = μ − θX
X* = μ/θ,   Z* = γμ/(kθ).

Here Zref is a fixed positive reference. Below the target μ/θ, memory grows and increases output production; above it, memory shrinks. At a positive steady state, the output therefore returns to μ/θ even if γ changes. But when the last Z molecule is removed, both its replication and output production stop. Zero memory cannot restart itself.

I compared the continuous equations with Gillespie simulations of the same four reactions.2 At time 10, I halved output removal. The deterministic model lowers memory from 10 to 5 and restores output to 20. In contrast, 190 of 200 stochastic runs lose all memory by time 40. Of these, 31 fail before the change: extinction is already possible without that disturbance. The first four seeds are shown without filtering.

"""Figure 1: a count-based teaching model, not a fit to biological data.

One chain of logic, read panel by panel:
  A  The circuit. Memory Z copies itself while output X is below 20 and is
     removed by X above it, so ln(Z/Zref) integrates 0.05*(20 - X). Every Z
     reaction has rate proportional to Z, so Z = 0 can never be left.
  B  At t = 10 output removal halves (gamma 1 -> 0.5). The ODE re-sets Z
     from 10 to 5 and X returns to 20 (perfect adaptation).
  C  Counted molecule by molecule, Z can hit 0. Once it does, X just decays.
  D  How often that happens, across all 200 seeds.

Every number printed on the figure is computed below and saved in the .json;
the caption file maps each claim to the JSON key that backs it.

Run: python lecture10_autocatalytic_memory.py
Requires numpy, scipy and matplotlib. Outputs are saved beside this script.
"""
from pathlib import Path
import json
import numpy as np
import matplotlib.pyplot as plt
from matplotlib.patches import FancyBboxPatch
from matplotlib.ticker import MaxNLocator
from scipy.integrate import solve_ivp

MU, THETA, K = 1.0, 0.05, 2.0
GAMMA_BEFORE, GAMMA_AFTER = 1.0, 0.5
SWITCH, END = 10.0, 40.0
INITIAL = [10, 20]  # Z, X: molecule counts in one fixed compartment
SEEDS = range(200)
SHOWN = 4           # first four seeds are drawn, unfiltered
TARGET = MU/THETA   # X at which Z neither grows nor shrinks
# Time is in arbitrary units (a.u.). MU, K, gamma: a.u.^-1;
# THETA: molecule^-1 a.u.^-1 (the fixed volume is absorbed here).
COLORS = ["#0072B2", "#D55E00", "#009E73", "#CC79A7"]
INK, GREY = "#182028", "#8b949e"


def simulate(seed):
    """Gillespie direct method; restart the event clock at the rate step."""
    rng = np.random.default_rng(seed)
    t, z, x = 0.0, *INITIAL
    times, states, extinction = [t], [[z, x]], None
    changes = np.array([[1, 0], [-1, 0], [0, 1], [0, -1]])
    while t < END:
        gamma = GAMMA_BEFORE if t < SWITCH else GAMMA_AFTER
        rates = np.array([MU*z, THETA*x*z, K*z, gamma*x])
        total = rates.sum()
        if total == 0:
            break
        event_time = t + rng.exponential(1/total)
        if t < SWITCH <= event_time:
            t = SWITCH
            times.append(t)
            states.append([z, x])
            continue
        if event_time > END:
            break
        t = event_time
        reaction = np.searchsorted(np.cumsum(rates), rng.random()*total)
        z, x = np.array([z, x]) + changes[reaction]
        assert z >= 0 and x >= 0
        if z == 0 and extinction is None:
            extinction = t
        times.append(t)
        states.append([z, x])
    times.append(END)
    states.append([z, x])
    return np.array(times), np.array(states), extinction


def deterministic():
    def rhs(gamma):
        return lambda t, y: [(MU-THETA*y[1])*y[0], K*y[0]-gamma*y[1]]
    a = solve_ivp(rhs(GAMMA_BEFORE), [0, SWITCH], INITIAL,
                  t_eval=np.linspace(0, SWITCH, 201), rtol=1e-9, atol=1e-11)
    b = solve_ivp(rhs(GAMMA_AFTER), [SWITCH, END], a.y[:, -1],
                  t_eval=np.linspace(SWITCH, END, 601), rtol=1e-9, atol=1e-11)
    assert a.success and b.success
    return np.r_[a.t, b.t[1:]], np.c_[a.y, b.y[:, 1:]]


def wilson(k, n, z=1.96):
    """95% Wilson score interval for a binomial proportion k/n."""
    p = k/n
    centre = (p + z*z/(2*n)) / (1 + z*z/n)
    half = z*np.sqrt(p*(1-p)/n + z*z/(4*n*n)) / (1 + z*z/n)
    return centre-half, centre+half


def draw_circuit(ax):
    """Panel A: the four reactions as a picture, rate laws beside the arrows."""
    ax.set(xlim=(0, 10), ylim=(0, 6.4))
    ax.axis("off")
    for x0, name, sub in [(1.0, "Z", "memory"), (6.6, "X", "output")]:
        ax.add_patch(FancyBboxPatch((x0, 2.4), 2.4, 1.6, boxstyle="round,pad=0.1",
                                    fc="#eef3f8", ec=INK, lw=1.4))
        ax.text(x0+1.2, 3.35, name, ha="center", va="center", fontsize=20,
                fontweight="bold", color=INK)
        ax.text(x0+1.2, 2.75, sub, ha="center", va="center", fontsize=9, color="#4a5560")
    arrow = dict(arrowstyle="-|>", lw=1.6, color=INK, mutation_scale=14)
    block = dict(arrowstyle="-[", lw=1.6, color="#C0392B", mutation_scale=8)
    ax.annotate("", (6.5, 3.6), (3.5, 3.6), arrowprops=arrow)
    ax.text(5.0, 3.85, "Z makes X:  k·Z", ha="center", fontsize=9.5)
    ax.annotate("", (3.5, 2.8), (6.5, 2.8), arrowprops=block)
    ax.text(5.0, 2.25, "X removes Z:  θ·X·Z", ha="center", fontsize=9.5, color="#C0392B")
    ax.annotate("", (1.6, 4.15), (2.8, 4.15),
                arrowprops=dict(arrow, connectionstyle="arc3,rad=1.6"))
    ax.text(2.2, 5.45, "Z copies itself:  μ·Z", ha="center", fontsize=9.5)
    ax.annotate("", (7.8, 1.3), (7.8, 2.3), arrowprops=arrow)
    ax.text(7.8, 0.95, "X removed:  γ·X", ha="center",
            va="center", fontsize=9.5)
    ax.text(0.1, 0.05, f"dZ/dt = (μ − θX)·Z  →  Z > 0 rests only at X = μ/θ = {TARGET:g}\n"
            "d ln(Z/Zref)/dt = μ − θX; Z = 0 is absorbing.",
            ha="left", va="top", fontsize=9.5, color=INK)


def make_figure():
    runs = [simulate(seed) for seed in SEEDS]
    deaths = [run[2] for run in runs]
    died = np.sort([t for t in deaths if t is not None])
    count, n = len(died), len(runs)
    low, high = wilson(count, n)
    before = int(np.sum(died < SWITCH))
    ode_t, ode_y = deterministic()
    shown_dead = [s for s in range(SHOWN) if deaths[s] is not None]
    print(f"Z extinct by t={END:g}: {count}/{n} (95% CI {low:.2f}-{high:.2f}); "
          f"{before} before the switch")
    print(f"ODE final Z={ode_y[0,-1]:.6f}, X={ode_y[1,-1]:.6f}")
    print(f"Shown seeds that went extinct: {shown_dead}")

    plt.rcParams.update({"font.family": "sans-serif", "font.sans-serif": ["DejaVu Sans"],
                         "font.size": 11,
                         "svg.fonttype": "none", "pdf.fonttype": 42,
                         "axes.spines.top": False, "axes.spines.right": False})
    fig, axes = plt.subplots(2, 2, figsize=(11, 8.6))
    fig.subplots_adjust(left=.07, right=.98, bottom=.08, top=.9, wspace=.25, hspace=.5)
    (a, b), (c, d) = axes
    titles = ["A   The circuit: logarithmic memory",
              "B   ODE: output returns to 20",
              "C   After Z vanishes, X decays",
              f"D   {count} of {n} runs lose Z by t = {END:g}"]
    for ax, title in zip(axes.flat, titles):
        ax.set_title(title, loc="left", fontsize=12, pad=10, fontweight="bold")

    draw_circuit(a)

    # B: the deterministic story, both species on one axis
    b.plot(ode_t, ode_y[0], color=COLORS[0], lw=2.4, label="Memory Z")
    b.plot(ode_t, ode_y[1], color=COLORS[1], lw=2.4, label="Output X")
    b.axhline(TARGET, color="#606870", lw=1.2, ls=":", label=f"Target X = {TARGET:g}")
    b.legend(frameon=False, fontsize=9.5, loc="center right")

    # C: same model, counted; first four seeds with the ODE behind them
    c.plot(ode_t, ode_y[1], color=INK, lw=2.6, alpha=.35, label="ODE X")
    for seed, color in enumerate(COLORS):
        t, y, death = runs[seed]
        c.step(t, y[:, 1], where="post", lw=1.2, color=color, label=f"Seed {seed} X")
        if death is not None:
            c.plot(death, y[np.searchsorted(t, death), 1], "x", color=color, ms=9, mew=2.2)
    c.axhline(TARGET, color="#606870", lw=1.2, ls=":", label="Target X = 20")
    c.plot([], [], "x", color=GREY, ms=9, mew=2.2, label="Z reaches 0")
    c.legend(frameon=False, fontsize=8.5, ncol=2, loc="upper right")

    # D: cumulative fraction of all 200 runs whose Z has reached 0
    frac = np.arange(1, count+1) / n
    d.step(np.r_[0, died, END], np.r_[0, frac, frac[-1] if count else 0],
           where="post", color=INK, lw=2)
    d.errorbar(END, count/n, yerr=[[count/n-low], [high-count/n]], fmt="o",
               color=INK, capsize=4, ms=4)
    d.text(END-1, low-.14, f"{count/n:.0%} (95% CI {low:.0%}–{high:.0%})",
           ha="right", va="top", fontsize=9.5)
    d.set_ylim(0, max(high*1.15, .05))
    d.set_ylabel("Fraction of runs with Z = 0")

    for ax in (b, c, d):
        ax.axvline(SWITCH, color=GREY, lw=1, ls="--")
        ax.set(xlim=(0, END+0.5), xlabel="Time (a.u.)")
        ax.yaxis.set_major_locator(MaxNLocator(integer=ax is not d, nbins=5))
    b.set_ylabel("Molecules (ODE)")
    c.set_ylabel("Output X (molecules)")
    c.set_ylim(bottom=-1)
    b.text(SWITCH+0.4, 14, "γ 1 → 0.5", fontsize=9, color=GREY, va="top")

    fig.suptitle("Autocatalytic memory: continuous recovery, discrete extinction", fontsize=13.5)

    stats = {"seeds": list(SEEDS), "horizon": END, "extinct": count,
             "extinct_fraction_ci95": [low, high], "extinct_before_switch": before,
             "shown_seeds": list(range(SHOWN)), "shown_seeds_extinct": shown_dead,
             "extinction_times": deaths, "ode_final": ode_y[:, -1].tolist(),
             "parameters": {"mu": MU, "theta": THETA, "k": K,
                            "gamma_before": GAMMA_BEFORE, "gamma_after": GAMMA_AFTER,
                            "switch": SWITCH, "initial_Z_X": INITIAL}}
    return fig, stats

What I would argue against / where this breaks

Adding ∅ → Z at constant rate ε removes the absorbing boundary: at zero memory, the mean waiting time for a new molecule is 1/ε. Yet it also changes the deterministic balance:

dZ/dt = ε + (μ − θX)Z
X* = μ/θ + ε/(θZ*).

For the post-change parameters above, ε = 0.1 gives X* ≈ 20.39, about 2% above the original target, and a mean restart waiting time of 10 time units. This source makes restart possible; it does not guarantee sustained regulation. The added flux allows memory to rest with nonzero error, so exact adaptation to changes in γ is lost.

Where this breaks. These are idealized, well-mixed reactions without division or resource limits. The extinction fraction depends on rates, initial counts and observation time. The equilibrium formula with ε is deterministic; it is not a formula for the stochastic mean. Recovery and precision must be assessed separately.
